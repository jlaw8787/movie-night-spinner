# Starship Troopers (1997)

Layout: newspaper (kept, "The lunch counter menu" remapped to "The mess hall menu"). Venue: FedNet, "FedNet. Would you like to know more?" (the lead).

## Venue
FedNet is the Federation news network whose bulletins break up the film, with the tag "Would you like to know more?". It is a broadcast shown on screen, not a room, which suits the newspaper layout. https://en.wikipedia.org/wiki/Starship_Troopers_(film)
