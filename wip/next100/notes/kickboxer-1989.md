# Kickboxer (1989)

Layout: bartab (kept). Venue: The Bangkok Bar, the bar where Xian gets Kurt drunk and goads the room into a fight to test him (the scene with Kurt's dance). The bar is never named in my sources, so it is given a plain name. Logo panel set to "Now showing" because the poster already carries the title.
